# Propósito 
El mini proyecto busca representar una evolución gradual hacia un sistema web centralizado que permita consultar disponibilidad, reservar y administrar tutorías con reglas explícitas.

# Problema
Actualmente, la información para la reserva de tutorías se encuentra dispersa en distintos medios y la confirmación de una reserva depende de varios intercambios entre estudiantes, tutores y coordinación.

# Usuario primario

Estudiantes universitarios que necesitan consultar la disponibilidad de tutorías y realizar reservas para recibir apoyo académico en cursos del área de Ingeniería de Software.

# Valor prometido
Centralizar la información de disponibilidad y reservas de tutorías en una única fuente, permitiendo que los estudiantes consulten la disponibilidad y realicen reservas, y que tutores y coordinación administren el proceso de acuerdo con reglas de negocio verificables.

# Restricciones conocidas

- Cantidad total de tutores disponibles: 6
- Cantidad total de materias disponibles: 4
- Tiempo máximo por sesión : 50 minutos
- Máximo de reservas activas simultáneamente: 2
